# CxChanger Voron 2.4 R2 Engineering Manual

The complete illustrated 38-page PDF is supplied in the accompanying download bundle. It covers mechanical assembly, BOM/prerequisites, Maxwell coupling, dock coordinates and XY paths, wiring architecture, Klipper integration, calibration, OrcaSlicer, commissioning, troubleshooting and maintenance.

**Important:** PDF/manual content is an engineering adaptation, not an official Voron document. Heater/sensor pins and dock coordinates must be measured on the target machine. Motion must remain disabled until the physical path is validated. See `patches/UPSTREAM_REVIEW_AND_CHANGES.md` for the reviewed issues and changes.
